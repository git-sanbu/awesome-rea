## 質問

REA ツールの説明と分析をローカル モデルの 32K コンテキストにどのように適合させることができますか?

## REAがしたこと

作成者は PR #3026 コミット d993ffeb1 および Ghidra 12.1.4. ツール ファミリと OpenCode ホワイトリストを使用して、10 REA ツールのみを公開します。モデルはターゲットを開き、関数を見つけて逆コンパイルしてから、セッションを閉じます。

## 著者が報告した結果

著者は、すべての 206 ツールの説明が文脈を超えていると報告しています。 62-tool セットアップは、プロンプトを読んだ後に GPU リセットを実行しました。 10-tool プロンプトでは、4、407 トークンが使用されました。 3 回の実行でターゲット文字列が見つかり、チェッカーが説明されました。それぞれの実行に約 80 秒かかりました。

## 制限と未検証の主張

3 つの実行では、3 つの独立したタスクではなく、1 つの小さなプログラムとプロンプトが繰り返されます。他のモデルやクライアントは比較されませんでした。結果は履歴 PR コミットを使用します。ツールの数、スイッチ、タイミングは現在のリリースでは保証されません。

## 何を学ぶか

最小限のツール セットをテストする前に、スキーマ コンテキストのコストを測定します。 1 つのタスクを繰り返しても、一般的な能力は確立されません。

## ソース内の REA 使用の証拠

抜粋の書式設定が簡素化されています。完全な文脈については、元のソースを読んでください。
