## Additions and evidence boundaries

### Open Claude UI

- [Caho1/open-claude-ui](https://github.com/Caho1/open-claude-ui), reviewed commit `c1f923ae0051a871941b98a0e2e3183a545e6a85`.
- Read README, versioned overview, interaction chapter and `RichComposerWithMentions.tsx`. The chapter attributes its investigation to REA 6.5.0 and names a macOS desktop baseline; the implementation explicitly attributes its input-composition rules to REA findings.
- The concrete question is how input composition and other interface rules inform reusable components. Documentation and implementations are public output.
- Do not adopt “production-grade”, fidelity or complete-client claims as verified facts. No raw REA session or independent behavioral/visual comparison suite was found in the reviewed files. The desktop version remains an author-reported baseline.

### Open Scrantic

- [glauberlima/open-scrantic](https://github.com/glauberlima/open-scrantic), reviewed commit `8c049614158f2adb09e517ce9e29da89e8a3ac38`.
- Read README's AI disclosure, `docs/ENGINE.md`, RNG implementation and INI handling. The developer explicitly credits REA and Claude Code with disassembling/decompiling `SCRANTIC.SCR`, recovering formats and script semantics, and writing the Rust engine.
- Engine notes describe TTM/ADS instructions, scheduling, 16-bit behavior and deliberate rendering differences. These support an engine-reconstruction case, not independently matched frames or platforms.
- Original screensaver files remain a user-supplied dependency. The catalog does not reproduce download/security-bypass instructions or redistribute the required commercial assets.

### REA Safe Agent

- [dagoSte/rea-safe-agents](https://github.com/dagoSte/rea-safe-agents), reviewed commit `c6f45cd27f1ed8ca774d5438d86d4b4f81c484fe`.
- Read README, `docs/validation.md`, dated live Claude/Codex JSON receipts, `tunnel.py` and `agent_session.py`. This is implemented MCP integration with public functional evidence, rather than an installation recommendation.
- Two macOS ARM64 receipts for the same benign ELF list 11 and 9 completed REA calls respectively. The validation record separately reports 39 successful calls on F-Droid 2.0.2; these are separate runs.
- Receipts remain author-published. The controller/runtime are trusted, analyzed text reaches model services, and Windows Docker integration is experimental. A clean npm audit and remaining whole-image vulnerability findings concern different scopes; neither establishes independently certified containment.
