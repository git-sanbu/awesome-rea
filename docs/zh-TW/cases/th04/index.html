TH04：恢復 PC-98 彈幕環形角度演算法

想解決什麼問題

環形彈幕如何均勻展開，併疊加瞄準玩家的方向？

REA 具體做了什麼

REA + Ghidra 驗證裝載佈局，分析輔助函式、讀取指令與原始位元組；結合既有重建專案解釋定點角度、整數除法與環繞。

原作者報告的成果

案例給出 REA 新檢查結果，並引用歷史 Turbo C++ 檢查：包含該輔助函式的 2,139 位元組範圍匹配。

歷史原始碼重建和編譯驗證來自 TH04 專案；REA 新檢查只是其中一部分證據。不是完整遊戲等價，也不是全部成果由 REA 獨立生成。
