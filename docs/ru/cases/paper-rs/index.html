Sketch (formerly paper-rs): бесконечный холст Rust, вдохновленный Paper.

Это издание является машинным переводом редакционной английской версии. Оригинальные цитаты остаются на исходном языке. Если формулировка неясна, обратитесь к английскому языку и связанным источникам. Английская версия

Цель: Поведение настольного приложения для проектирования Paper

Автор/атрибуция: michaelshimeles

Дата проверки источника: 2026-10-21

Статус проверки: Источники рассмотрены; авторские тесты самостоятельно не перепроводятся.

Вопрос

Как взаимодействие холста, макета и редактора может стать основой для независимого инструмента дизайна?

Что сделал REA

Автор утверждает, что REA и Claude Code использовались для исследования поведения рабочего стола Paper перед созданием отдельного приложения Rust с помощью wgpu, winit и egui.

Результаты, сообщенные автором

Проект публикует бесконечный холст, страницы, макеты, векторное редактирование, виртуальную доску и интерфейсы MCP с тестами и различиями в функциях. Рассмотренный на 2026-10-21:, он теперь называется Sketch, с исполняемым файлом Sketch-rs, миграцией при первом запуске старого каталога проекта и совместимостью со старыми файлами и переменными среды. Остается один случай.

Ограничения и непроверенные претензии

Автор явно не запускал его на реальном железе macOS. Некоторые функции приблизительны или отсутствуют. Включение основано на публичном указании автора, а не на подтвержденной эквивалентности Paper.

Чему научиться

Изучите контракты поведения и взаимодействия, устанавливая границы независимой реализации.
