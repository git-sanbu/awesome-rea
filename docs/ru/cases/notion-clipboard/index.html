Вопрос

Как веб-редактор записывает форматированный текст через буфер обмена рабочего стола?

Что сделал REA

REA статически анализирует предварительную загрузку вкладки, чтобы найти контекстный мост и вызов IPC. Прямое чтение связанного кода заполняет API буфера обмена, каналы и приемник основного процесса.

Результаты, сообщенные автором

В витрине объясняется механизм рендеринга → предварительная загрузка → IPC → main на уровне исходного кода и демонстрируются маркеры форматированного текста и таблицы Markdown в независимом модульном тесте.

Ограничения и непроверенные претензии

График REA не разрешал автоматически полную цепочку каналов буфера обмена. Веб-редактор и пакет рабочего стола не соответствуют образцам среды выполнения; настоящий copy/paste не был зафиксирован в той же версии.

Чему научиться

Отдельные структуры, возвращаемые REA, выводы ручного чтения кода и результаты независимых зондов.
