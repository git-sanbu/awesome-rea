Локальная модель 27B: меньший список инструментов MCP позволяет выполнять функциональный анализ.

Это издание является машинным переводом редакционной английской версии. Оригинальные цитаты остаются на исходном языке. Если формулировка неясна, обратитесь к английскому языку и связанным источникам. Английская версия

Цель: Self-built C token checker; Qwen3.8-27B, llama.cpp, OpenCode and REA MCP

Автор/атрибуция: CassieFox23

Дата проверки источника: 2026-10-19

Статус проверки: Источники рассмотрены; авторские тесты самостоятельно не перепроводятся.

Вопрос

Как описания и анализ инструментов REA могут вписаться в контекст 32K локальной модели?

Что сделал REA

Автор использует PR #3026 для фиксации семейств инструментов d993ffeb1 и Ghidra 12.1.4., а список разрешений OpenCode предоставляет только инструменты 10 REA; модель открывает цель, находит и декомпилирует функцию, а затем закрывает сеанс.

Результаты, сообщенные автором

Автор сообщает, что все описания инструмента 206 выходят за рамки контекста. При установке 62-tool произошел сброс графического процессора после прочтения подсказки. В приглашении 10-tool использовались токены 4, 407; три прогона нашли целевую строку и объяснили программу проверки, каждый из которых занимал около 80 секунд.

Ограничения и непроверенные претензии

The three runs repeat one tiny program and prompt, not three independent tasks. No other model or client was compared. Results use a historical PR commit; количество инструментов, переключатели и тайминги не являются гарантией для текущей версии.

Чему научиться

Measure schema context cost before testing a minimal tool set. Повторение одной задачи не устанавливает общих способностей.
