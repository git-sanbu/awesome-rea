Дата проверки источника: 2026-10-16

Вопрос

Как можно перенести захват, кодирование, звук и ввод в Linux, сохранив при этом библиотеку протоколов?

Что сделал REA

Автор утверждает, что Claude Code и REA анализируют оба пакета. Библиотека протокола macOS, предоставленная считывателем, используется повторно, а уровень платформы Linux переписывается.

Результаты, сообщенные автором

Публичный порт Linux включает исходный код, инструкции по сборке и тесты с имитацией гарнитуры с использованием PipeWire/X11, GStreamer и uinput.

Ограничения и непроверенные претензии

Никаких реальных тестов гарнитуры, Wi-Fi или графического кодера не проводилось. Игровые функции SteamVR/OpenXR стримера Windows не поддерживаются. Зависимость от библиотеки протоколов поставщика означает, что это не полностью независимая перезапись протокола.

Чему научиться

Сосредоточьте работу по обеспечению совместимости на границах платформы и отличайте тесты на моделируемых устройствах от приемки реального оборудования.
