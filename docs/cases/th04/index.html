TH04：恢复 PC-98 弹幕环形角度算法

PC-98 DOS bullet-ring maths

分析目标：东方幻想乡 TH04 的 PC-98 DOS MZ、16 位实模式程序

作者 / 归属：REA 官方案例团队；原项目作者见来源

核对日期：2026-10-16

收录状态：已阅读公开来源，未独立复跑作者测试

想解决什么问题

环形弹幕如何均匀展开，并叠加瞄准玩家的方向？

REA 具体做了什么

REA + Ghidra 验证装载布局，分析辅助函数、读取指令与原始字节；结合既有重建项目解释定点角度、整数除法与环绕。

案例给出 REA 新检查结果，并引用历史 Turbo C++ 检查：包含该辅助函数的 2,139 字节范围匹配。
