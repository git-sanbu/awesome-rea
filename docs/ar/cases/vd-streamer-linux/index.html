Virtual Desktop Streamer: منفذ Linux من خلال طبقة منصة بديلة

تمت ترجمة هذه الطبعة آليًا من النسخة الإنجليزية التحريرية. تبقى الاقتباسات الأصلية في لغتها المصدر. عندما تكون الصياغة غير واضحة، راجع اللغة الإنجليزية والمصادر المرتبطة. النسخة الانجليزية

الهدف: حزم التثبيت الرسمية Virtual Desktop macOS وWindows

المؤلف / الإسناد: cudanexus

تاريخ مراجعة المصدر: 2026-10-16

حالة المراجعة: تمت مراجعة المصادر؛ لا يتم إعادة تشغيل اختبارات المؤلف بشكل مستقل.

السؤال

كيف يمكن نقل الالتقاط والتشفير والصوت والإدخال إلى Linux مع الاحتفاظ بمكتبة البروتوكول؟

ما فعله REA

يذكر المؤلف أن Claude Code وREA يقومان بتحليل كلا الحزمتين. تتم إعادة استخدام مكتبة بروتوكول macOS التي يوفرها القارئ، بينما تتم إعادة كتابة طبقة النظام الأساسي Linux.

النتائج التي أبلغ عنها المؤلف

يشتمل منفذ Linux العام على تعليمات المصدر والإنشاء واختبارات محاكاة سماعات الرأس باستخدام PipeWire/X11 وGStreamer وuinput.

القيود والمطالبات التي لم يتم التحقق منها

لم يتم إجراء أي اختبارات حقيقية لسماعات الرأس أو Wi-Fi أو وحدة معالجة الرسومات. ميزات لعبة SteamVR/OpenXR الخاصة بجهاز البث Windows غير مدعومة. الاعتماد على مكتبة بروتوكول البائع يعني أن هذه ليست إعادة كتابة بروتوكول مستقلة تمامًا.

ماذا نتعلم

تركيز عمل التوافق على حدود النظام الأساسي وتمييز اختبارات الأجهزة المحاكاة عن قبول الأجهزة الحقيقية.
