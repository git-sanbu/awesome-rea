REA ने क्या किया

लेखक-रिपोर्ट किए गए परिणाम

लेखक files/. के तहत फ़ंक्शन, स्ट्रिंग और कॉल-पथ जांच, परिणाम.txt और कच्चे JSON आउटपुट प्रकाशित करता है

सीमाएँ और असत्यापित दावे

यह एक विशिष्ट निर्माण का स्थैतिक विश्लेषण है। आयात और स्यूडोकोड अकेले प्रत्येक रनटाइम व्यवहार को स्थापित नहीं करते हैं या सुरक्षा प्रमाणन का गठन नहीं करते हैं।
