質問

弾丸はどのようにしてリングの周りに均等に分散され、プレイヤーに向けられるのでしょうか?

REAがしたこと

REA および Ghidra は、ロード レイアウトをチェックし、ヘルパー関数を分析し、命令と生のバイトを読み取ります。既存の再構成プロジェクトは、固定小数点角度、整数の除算、およびラッピングのコンテキストを提供します。

著者が報告した結果

ショーケースでは、新しい REA チェックと、過去の Turbo C++ 検証 (ヘルパー マッチを含む 2、139-byte 領域) が表示されます。

制限と未検証の主張

史料の再構築と編纂チェックは TH04 プロジェクトに属します。新しい REA 調査は証拠の一部にすぎず、ゲーム全体の同等性や REA の唯一の著作者の証明ではありません。
