يجب أن يُظهر المصدر الأساسي العام بوضوح استخدام REA وسؤالًا ملموسًا وعملية ومخرجات. ويعزى التحليل والتنفيذ المستقل والعمل التاريخي بشكل منفصل. نرحب بالتجارب والتقييمات الفاشلة وتكاملات REA. يتم استبعاد مقدمات الأدوات والمرايا والخطط غير المنفذة.
